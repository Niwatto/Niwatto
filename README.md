## What I'm building

- **POS platform** — Flutter app (clean architecture + GetX) against a NestJS monorepo. Thermal printer drivers for 7+ brands across iOS and Android, plus an offline-first KDS on Couchbase Lite.
- **[SubBeep](https://github.com/Niwatto/SubBeep)** — Flutter app for tracking and managing subscriptions.
- **[rust-programing](https://github.com/Niwatto/rust-programing)** — learning Rust the slow, honest way.
- **Tooling** — dotfiles, Neovim config, Terragrunt stacks, and far too many Claude Code skills.
